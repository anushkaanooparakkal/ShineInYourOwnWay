# Shine in Your Own Way

A browser-based student growth and progress-tracking prototype created for a MULEARN college club program.

## About the Project

**Shine in Your Own Way** is designed to help students focus on their own growth instead of comparing themselves with others.

The prototype allows a student to:

- Discover and reflect on personal strengths
- Set personal goals
- Track progress toward goals
- Record activities and small achievements
- Receive mentor encouragement
- Earn badges for personal effort and growth
- Update their profile, interests, and reflection

The project intentionally avoids leaderboards and student-to-student rankings.

## Features

### Overview
- Personal dashboard
- Goals in progress
- Completed steps
- Skills explored
- Badges earned
- Recent activities
- Mentor feedback

### Discover Strengths
- Skill self-assessment
- Personal interests
- Reflection section
- Ability to update the strengths check-in

### My Goals
- Add personal goals
- Choose a skill area
- Set a target date
- Track progress
- Mark goals as completed

### Activities
- Maintain a personal activity journal
- Record the skill/goal connected to an activity
- Record optional time spent

### My Recognition
- Personal achievement badges
- Recognition based on effort and progress rather than comparison

### Profile
- Update name and class/year
- Update interests
- Add a personal reflection

## Technology Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

The application is contained in a single `index.html` file with the layout, styling, and functionality included.

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a modern web browser such as Chrome, Edge, Firefox, or Safari.
3. The application opens directly in the browser.
4. No installation, account, or backend server is required.

The application stores changes locally in the browser using Local Storage. Student data is not sent to a server.

## Development Note

This project was developed as an AI-assisted prototype using ChatGPT during the development process. The prototype was customized, tested, and presented based on the project concept.

## Current Limitations

- This is a prototype, not a multi-user production service.
- Data is stored locally in the browser.
- There is no backend database or authentication system.
- Mentor notes and student information are stored in the same browser/device.

## Future Scope

Possible future improvements include:

- User authentication and individual student accounts
- Cloud/database storage
- Separate student and mentor dashboards
- Secure mentor-student communication
- Progress analytics
- Mobile-friendly deployment as a web application
